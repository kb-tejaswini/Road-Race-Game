# Road Race

A motorbike racing and brawling game that runs in the browser. Pick a road, pick a weather pattern, and fight your way to first place. The roads include city streets, arctic towns with polar bears, a zombie outbreak and a volcano lava escape.

**Play it:** [Road Race Game](https://kb-tejaswini.github.io/Road-Race-Game/)

## Controls

**One player:** arrow keys to ride, Space or Z to punch, Enter or X to kick.

**Two players (split screen):**

| Action | Player 1 (left screen) | Player 2 (right screen) |
|---|---|---|
| Steer, throttle, brake | Arrow keys | W A S D |
| Punch | `.` or Right Shift | Z or Space |
| Kick | `/` or Enter | X |

The game needs a keyboard, so it's made for desktop browsers.

## Run it locally

Open `index.html` in any modern browser. There's nothing to install and no build step.
